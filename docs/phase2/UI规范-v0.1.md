# 阶段 2 UI 规范 v0.1

阶段目标：完成可演示的 Web 交互原型，优先保证 2D 星盘、宫位关系、高亮反馈和手势替代路径清晰稳定。

## 1. 布局

- 主界面采用三栏工作台：左侧建档和控制，中间 2D 十二宫星盘，右侧结构化占位卡片、时间轮、手势日志。
- 1120px 以下自动改为单栏，星盘保持固定比例，不因卡片内容变化而跳动。
- 十二宫使用 SVG 渲染，中心区域显示当前视图状态和星曜层级。

## 2. 色标

- 本宫：金色描边，用于当前选中宫位。
- 对宫：赤色描边，用于外部对照关系。
- 三合：青绿色描边，用于资源网络关系。
- 邻宫：紫色描边，用于近身边界关系。
- 未参与关系：低对比深色底，不抢占视线。

## 3. 星曜层级

- 主星层：每宫展示最多 3 个主星。
- 辅曜层：每宫展示最多 4 个辅曜。
- 四化层：每宫展示四化标签。
- 切换方式：分段控件、按钮替代、捏合手势都可触发。

## 4. 手势反馈

- 开掌：复位到全局视图。
- 食指点选：选中当前宫位，显示结构化占位卡。
- 捏合：切换主星、辅曜、四化层。
- 画圈：切换大限时间轮。
- 握拳：退出当前宫位，返回上层。
- 摄像头不可用时，必须显示模拟按钮，不阻断演示流程。

## 5. 日志与隐私

手势日志只允许记录：

- `type`
- `confidence`
- `timestamp`
- `action`
- `target_palace_id`
- `no_video_frame: true`

日志不得保存视频帧、人脸、背景图像、完整生日、出生时间或地点详情。

## 6. 解读占位

阶段 2 不输出正式命理解读。卡片只展示：

- 宫位名称和宫干地支。
- 主星、辅曜、四化。
- 对宫、三合、邻宫。
- “正式解读将在阶段 3 接入”的占位说明。
