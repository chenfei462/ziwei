# 阶段 2 演示脚本 v0.1

## 演示目标

在 3 分钟内完成一次“建档 → 开盘 → 点选宫位 → 高亮关系 → 切换大限 → 查看日志”的交互演示。

## 演示步骤

1. 打开原型首页，确认页面标题为“紫微星垣互动原型”。
2. 使用默认出生资料点击“开盘”。
3. 在中间 2D 星盘点击任意宫位，确认本宫、对宫、三合、邻宫被区分高亮。
4. 点击“切换星曜层”，确认星盘中心层级文案切换。
5. 点击“切换大限”，确认右侧大限时间轮更新。
6. 点击“模拟开掌”，确认视图复位并写入 `open_palm` 手势日志。
7. 展示“启用摄像头”按钮和模拟手势按钮，说明摄像头不可用时仍可完整演示。
8. 展示手势日志，强调 `no_video_frame`，不保存视频帧。

## 验收话术

本阶段已经完成交互原型，不生成正式命理判断。所有解读区域只显示结构化占位，正式专业/娱乐文案将在阶段 3「解读引擎」接入。
