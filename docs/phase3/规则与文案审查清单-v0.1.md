# 阶段 3 规则与文案审查清单 v0.1

## 顾问抽检

- 六个 MVP 宫位至少各抽检 3 个样例盘。
- 每条触发规则能说明为什么匹配当前宫位、星曜、四化或关系。
- 不允许单星断事；至少保留宫位主题或关系结构作为上下文。
- 置信等级必须来自规则权重，不允许文案自行宣称确定性。

## 内容安全

- 不使用“必然、一定、注定、肯定”等硬断词。
- 不使用恐吓式表达，例如灾祸、死亡、破产、离婚、绝症。
- 涉及投资、法律、健康、婚姻重大决策时，必须出现安全标记和专业咨询提醒。
- 娱乐模式只能软化表达，不改变底层规则结果。

## 隐私与日志

- `/api/interpret` 不返回完整出生日期、出生时间、地点详情或摄像头数据。
- 前端规则溯源只展示规则和命盘结构依据。
- 手势日志继续保持 `no_video_frame: true`。

## 阶段出口

- `npm test`、`npm run typecheck`、`npm run build`、`npm run test:e2e` 通过。
- 六宫点选后能展示正式解读，非六宫能明确返回未开放状态。
- 顾问完成规则表和文案模板抽检后，才能把阶段 3 标为专业验收通过。
