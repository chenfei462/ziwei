# 阶段 3「解读引擎」实施说明 v0.1

## 范围

阶段 3 已把 `/api/interpret` 从占位响应升级为规则驱动的结构化解读。当前只覆盖 MVP 六宫：

- 命宫 `life`
- 官禄 `career`
- 财帛 `wealth`
- 夫妻 `spouse`
- 福德 `fortune`
- 迁移 `migration`

其余宫位返回 `status: "not_open"`，前端显示“暂未开放深度解读”，不输出正式判断。

## 数据与规则

- `data/phase3/interpretation-rules-v0.1.json`：规则表 v0.1。每条规则包含 `rule_id`、层级、宫位范围、触发条件、权重、来源、短引文、现代转译、专业文案、娱乐文案、场景、建议和安全标记。
- `data/phase3/copy-templates-v0.1.json`：专业/娱乐模式的文案前缀、建议后缀与安全提示。
- `src/phase3/ruleMatcher.ts`：规则加载、条件匹配、置信等级与内容安全审查。
- `src/phase3/interpretationEngine.ts`：把匹配结果组装成 `InterpretResponse`。

## API 输出

`POST /api/interpret` 输入保持阶段 2 约定：

```json
{
  "chart_id": "chart_xxx",
  "palace_id": "life",
  "mode": "professional",
  "major_period_id": "period_1",
  "include_trace": true
}
```

正式响应包含：

- `status`：`ready` 或 `not_open`
- `interpretation.basis`：依据摘要
- `interpretation.interpretation`：解释文案
- `interpretation.scenario`：现实场景
- `interpretation.advice`：建议
- `interpretation.confidence`：`strong_structure`、`medium_structure`、`weak_structure`
- `interpretation.safety_flags`：安全标记
- `trace`：规则溯源链，只有 `include_trace: true` 时返回

## 前端更新

- 宫位卡片新增专业/娱乐切换。
- 点选宫位、切换模式或切换大限时，自动刷新解读。
- 已开放六宫展示依据、解释、现实场景、建议、置信等级和安全标记。
- 规则溯源可展开查看触发规则、来源、短引文、现代转译和权重。
- 摄像头手势日志仍只记录动作结构，不记录视频帧。

## 正确性边界

当前规则表是工程 v0.1，可用于联调与内容抽检；尚未完成紫微顾问逐条审定，因此不能标记为专业验收通过。Golden tests 仍需顾问确认规则链和文案边界后再冻结。
