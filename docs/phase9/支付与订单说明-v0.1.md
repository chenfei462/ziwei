# 支付与订单说明 v0.1

## 范围

阶段 9 将阶段 8 的报告草稿推进到最小商业闭环：创建订单、创建 `stripe_checkout` 会话、处理签名 webhook、授予报告权益。

## 订单状态

- `draft`：订单已创建，尚未进入支付。
- `pending_payment`：已创建 checkout session。
- `paid`：支付事件确认成功的中间状态。
- `fulfilled`：报告权益已授予。
- `failed` / `expired`：支付失败或 checkout 过期。
- `refunded_manual`：客服人工标记退款；本阶段不做自动退款。

## 接口

- `POST /api/order/create`
- `GET /api/order/{id}`
- `GET /api/order/list`
- `POST /api/checkout/session`
- `POST /api/payment/webhook`
- `GET /api/entitlement/report/{report_id}`
- `GET /api/member/me`
- `GET /api/commercial/dashboard`

## 隐私

订单、支付事件、权益和看板只保存 `report_id`、`member_id`、金额、状态和脱敏报告快照，不保存完整出生日期、出生时间、地点详情、摄像头帧或背景图像。
