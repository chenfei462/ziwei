# 合规与客服文档 v0.1

## 购买前告知

- 服务说明：报告用于传统文化娱乐、自我观察和内容辅助。
- 隐私说明：默认隐藏完整生日、出生时间和地点详情。
- 退款说明：阶段 9 仅支持人工客服标记退款，不做自动退款。
- 免责声明：报告不替代医疗、法律、财务、心理或婚恋重大决策建议。

## 异常订单处理

- 未支付：保留 `pending_payment` 状态，可重新创建 checkout session。
- 支付失败：记录 `failed`，不授予权益。
- webhook 重复：按 `payment_event_id` 幂等处理。
- 签名失败：返回 `PAYMENT_WEBHOOK_SIGNATURE_INVALID`，不改变订单状态。
- 人工退款：客服核对后标记 `refunded_manual`。
