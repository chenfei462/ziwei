## 7. 阶段 0 风险清单

| 风险 | 影响 | 处理方式 | 状态 |
| --- | --- | --- | --- |
| 无专家预期结果时样例盘不能作为断言 | 阶段 1 排盘正确性不可验收 | 顾问必须补齐 `expected_*` 字段 | 开放 |
| 子时和闰月口径存在派别差异 | 排盘结果与外部工具不一致 | 配置化并在样例盘备注口径 | 开放 |
| 娱乐文案被理解为预测 | 合规和用户心理风险 | 强制安全标记和禁用词审查 | 开放 |
| 手势识别受光线影响 | 体验不稳定 | 普通按钮入口必须完整 | 开放 |
| 古籍来源与现代注解版权 | 商业上线风险 | 优先公版来源，现代注解另做授权审查 | 开放 |

## 8. 阶段 1 开工门槛

阶段 1「排盘引擎」只能在以下条件满足后开始：

- 产品经理确认 `需求文档 v0.1`。
- 紫微顾问确认 `规则口径说明 v0.1`。
- 紫微顾问补齐样例盘预期结果，至少 20 个案例可用于自动化断言。
- 后端/算法工程师确认 API 草案足以实现排盘引擎。
- QA 确认样例盘数据可以转入测试工程。
- 内容设计确认知识库字段足以支持六宫解读模板。
