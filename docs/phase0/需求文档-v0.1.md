## 1. 产品定义

「紫微星垣互动」是一个面向 Web MVP 的紫微斗数文化娱乐型命盘探索产品。用户输入出生资料后获得可解释的紫微命盘，并通过点选、缩放、高亮和后续手势交互探索十二宫、三方四正、限运和星曜关系。

产品定位是「传统文化解释 + 自我观察 + 娱乐化互动」，不是医疗、法律、投资、婚恋或其他重大决策建议工具。

## 2. 阶段 0 目标

阶段 0 的目标不是开发可运行产品，而是冻结阶段 1 可直接使用的 MVP 基线：

- 锁定 MVP 必做与暂缓范围。
- 锁定排盘规则默认口径与可配置项。
- 建立首批样例盘数据表结构和 30 个校验种子案例。
- 建立原典知识库 v0.1 骨架。
- 冻结 API 输入输出意图，供阶段 1 排盘引擎实现。
- 明确内容安全、隐私与合规底线。

## 3. 目标用户

| 用户类型 | 核心需求 | 阶段 0 对应约束 |
| --- | --- | --- |
| 命理爱好者 | 排盘准确、规则透明、依据清楚 | 排盘口径必须文档化，解读必须可溯源 |
| 国风/玄学兴趣用户 | 氛围感、有趣、可分享 | 娱乐表达必须来自同一底层命盘，不篡改专业结果 |
| 内容创作者/咨询师 | 快速生成结构化素材 | 阶段 0 只冻结报告与分享图意图，不做编辑器 |
| 线下展陈/活动方 | 大屏和无接触互动 | 阶段 0 只保留兼容考虑，Web MVP 优先 |

## 4. MVP 必做范围

| 模块 | 必做范围 | 验收口径 |
| --- | --- | --- |
| 出生资料输入 | 公历/农历、日期、时间、时区、地点、传统算法性别字段、是否闰月、是否启用真太阳时 | 字段进入 API 草案，敏感信息标注清楚 |
| 排盘 | 安命身、十二宫、十四主星、主要辅曜、四化、大限 | 阶段 1 使用样例盘自动化校验 |
| 解读 | 命宫、官禄、财帛、夫妻、福德、迁移六宫 | 每条解读可回到规则、宫位、星曜、关系结构 |
| 交互 | 普通按钮和鼠标/触控可完成全流程；手势 MVP 为开掌、点选、捏合、画圈、握拳 | 手势不是唯一入口 |
| 视觉 | 2D 十二宫星盘、宫位高亮、三方四正连线、解读卡片 | 不做 3D、AR 或复杂粒子 |
| 报告/分享 | 网页报告和基础分享图，默认隐藏完整生日 | 不做 PDF/DOCX 编辑器 |
| 安全与隐私 | 出生资料最小化存储；摄像头端侧识别；分享图默认脱敏 | 文案不输出硬断或恐吓式结论 |

## 5. 暂缓范围

| 模块 | 暂缓内容 | 暂缓原因 |
| --- | --- | --- |
| 排盘 | 流月、流日、多派别完整切换、复杂历史时区 | 避免阶段 1 排盘引擎过宽 |
| 解读 | 全十二宫深度报告、合盘全量分析、格局完整扫描 | 先验证六宫与规则链质量 |
| 手势 | 翻掌、V 手势、双手拉开、多人交互 | 优先保证 5 个核心手势稳定 |
| 视觉 | 3D 星垣、AR、复杂粒子特效、大屏专用模式 | Web MVP 先验证信息结构 |
| 商业化 | 付费报告、会员、创作者后台 | 阶段 0 不进入交易链路 |
| 导出 | PDF/DOCX 专业报告编辑器 | 阶段 0 只定义报告结构意图 |

## 6. 核心用户路径

1. 用户进入 Web 页面，看到星盘入口和普通按钮入口。
2. 用户创建出生档案，输入日历类型、出生日期、出生时间、时区、地点和传统算法字段。
3. 系统生成十二宫命盘，先高亮命宫与身宫。
4. 用户点选任意核心宫位，界面同时高亮本宫、对宫、三合宫和邻宫。
5. 用户在专业模式中查看依据、触发规则、现代转译和置信等级。
6. 用户切换到娱乐模式，查看同一底层结论的轻量化卡片。
7. 用户保存网页报告或生成脱敏分享图。

## 7. 专业模式与娱乐模式边界

| 项目 | 专业模式 | 娱乐模式 |
| --- | --- | --- |
| 数据来源 | 同一个 Chart 对象 | 同一个 Chart 对象 |
| 输出结构 | 依据、解释、现实场景、建议、置信等级 | 人格关键词、轻量建议、可分享表达 |
| 原典呈现 | 可显示短引文和现代白话解释 | 不展示艰涩原文，保留比喻和行动建议 |
| 风险表达 | 明确避免绝对预测 | 更强调文化体验和自我观察 |
| 敏感主题 | 降级为提醒和咨询专业人士建议 | 不输出疾病、投资、法律、婚恋硬结论 |

## 8. 内容安全与隐私底线

- 禁止使用绝对化、恐吓式、重大结果承诺类硬断表达。
- 高敏感主题只允许输出温和提醒和专业咨询建议。
- 出生日期、出生地点、关系档案都按敏感信息处理。
- 分享图默认隐藏完整出生日期、出生时间和出生地点。
- 摄像头只用于端侧手势识别，默认不上传视频帧。
- 手势日志只允许记录事件类型、置信度、时间戳和动作，不记录人脸、背景或原始视频。
