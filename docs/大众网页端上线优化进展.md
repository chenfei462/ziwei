- 新增 `src/analytics.ts` 和受保护的 `/api/ops/analytics/events`，记录建盘开始、建盘完成、解读查看、分享创建、订单创建、支付结果等关键事件。
- 收紧 `/api/support/ticket`：公开客服工单主体绑定服务端解析的当前 visitor/member 身份，前端不再提交用户标识；缺少既有会话或在请求体中冒充其他主体会失败关闭。工单详情读取和状态更新迁移到 `/api/ops/support/ticket/[id]`，旧公开 `/api/support/ticket/[id]` route file 已移除。
- 新增 `/api/privacy/delete-request`，隐私数据删除或账号注销会创建独立 `data_deletion_requests` 状态记录并关联客服工单；删除主体绑定服务端解析的当前 visitor/member 身份，缺少既有会话或在请求体中冒充其他主体会失败关闭；新增 `/api/ops/deletion-requests` 和 `/api/ops/deletion-request/[id]` 后台处理入口，完成、拒绝或取消必须二次确认并写入审计轨迹。
- 新增 `/app/internal/layout.tsx`，所有 `/internal/*` 页面统一要求管理员 header 并设置 noindex/noarchive；后台 MFA/等效第二因子已接入 `PHASE10_OPS_MFA_ENABLED`、`PHASE10_OPS_MFA_CODE`、`x-admin-mfa-code`、ops API 和 `/api/launch/config.ops_security` readiness，开启后缺失或错误第二因子会失败关闭。
