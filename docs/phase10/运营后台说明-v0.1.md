# 运营后台说明 v0.1

## 能力

- 查询订单、支付事件、报告权益和上线看板。
- 支持订单异常备注和人工退款标记。
- 支持客服工单创建、更新、分派和关闭；订单关联工单通过 `/api/ops/order/[id]/support-ticket` 从服务端订单归属绑定用户、报告和订单，避免后台前端冒充公开用户身份。
- `/internal/ops` 已挂载受保护的 Launch Ops Console，可加载订单、创建订单关联工单、标记人工退款、加载管理员审计日志，并通过 Sensitive Record Review 表单对 chart/report/order/share/support_ticket 执行二次确认 reveal。

## 权限

后台 API 通过 `x-admin-token` 和 `x-admin-role` 访问。`ops_admin` 可标记人工退款；`support_agent` 可查询和处理工单；`content_reviewer` 只用于内容与报告审查相关读取。敏感详情 reveal 只能由 `ops_admin` 执行，请求必须包含 record type、record ID、reason、`second_confirmed=true` 和可选 ticket ID；`support_agent` 与 `content_reviewer` 只能查看脱敏列表，调用 `/api/ops/sensitive-record` 必须被拒绝。

## 隐私

后台只展示 `order_id`、`report_id`、`member_id`、金额、状态和脱敏备注，不展示完整生日、出生时间、地点详情、摄像头帧或背景图像。`/api/ops/audit-logs` 和 `/internal/ops` 审计列表只展示脱敏 metadata。成功 reveal 后页面可以在管理员操作区展示单条敏感详情，但必须同时刷新 `ops_sensitive_record_revealed` 审计记录，且审计 metadata 不得包含完整生日、出生时间、地点、手机号、报告正文或支付密钥。
