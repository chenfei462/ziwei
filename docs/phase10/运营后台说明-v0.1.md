# 运营后台说明 v0.1

## 能力

- 查询订单、支付事件、报告权益和上线看板。
- 支持订单异常备注和人工退款标记。
- 支持客服工单创建、更新、分派和关闭。

## 权限

后台 API 通过 `x-admin-token` 和 `x-admin-role` 访问。`ops_admin` 可标记人工退款；`support_agent` 可查询和处理工单；`content_reviewer` 只用于内容与报告审查相关读取。

## 隐私

后台只展示 `order_id`、`report_id`、`member_id`、金额、状态和脱敏备注，不展示完整生日、出生时间、地点详情、摄像头帧或背景图像。
