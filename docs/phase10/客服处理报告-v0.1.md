# 客服处理报告 v0.1

## 工单分类

- `payment_failed`：支付失败。
- `unfulfilled`：已支付但权益未到账。
- `refund_request`：退款申请。
- `content_dispute`：报告内容争议。
- `privacy_deletion`：隐私删除请求。
- `general`：普通咨询。

## 处理口径

所有工单必须先确认用户已同意不提交完整出生资料。涉及退款时，客服记录原因并由运营后台标记 `refunded`；正式退款 API 接入前不执行自动退款。

后台从订单创建客服工单时使用 `/api/ops/order/[id]/support-ticket`，不得从前端提交或信任 `member_id`、`order_id`、`report_id` 主体字段。服务端会根据订单记录绑定会员、报告和订单，写入 `ops_support_ticket_created` 审计轨迹，并在订单备注中留下工单关联。
