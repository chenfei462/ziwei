# 运营素材包 v0.1

## 3 分钟演示脚本

1. 建档开盘：输入示例出生资料，说明默认隐藏完整出生信息。
2. 星盘探索：点选财帛宫，展示本宫、对宫、三合和邻宫高亮。
3. 解读与溯源：切换专业/娱乐模式，展开规则来源和安全提示。
4. 交互演示：使用按钮或手势替代路径切换星曜层级和大限。
5. Beta 验证：生成分享卡、收藏当前宫位、提交报告意向，再提交反馈。

## 短视频脚本

- 0-5 秒：十二宫星盘开盘画面。
- 5-15 秒：点选宫位后出现关系高亮和六宫解读。
- 15-25 秒：展开规则溯源，强调“同一命盘结果，专业/娱乐两种表达”。
- 25-35 秒：生成隐私保护分享卡和报告样张入口。
- 35-45 秒：邀请 Beta 用户反馈，不承诺绝对预测。

## 社群招募文案

我们正在进行紫微斗数互动星盘 Web Beta 测试，招募愿意体验“开盘、六宫解读、规则溯源、分享卡和报告样张”的用户。测试过程不上传摄像头画面，分享内容默认隐藏完整生日、出生时间和地点详情。当前版本为文化娱乐测试版，不作为医疗、法律、投资或婚姻重大决策依据。

## FAQ

- 是否收费：阶段 5 只收集报告意向，不接真实支付。
- 是否保存出生资料：分享卡、收藏和反馈默认不保存完整生日、出生时间和地点详情。
- 摄像头是否上传：手势识别默认端侧运行，Beta 事件不记录视频帧。
- 解读是否绝对：不会输出硬断、恐吓式表达或重大决策承诺。
