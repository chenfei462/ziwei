# 报告样张 v0.1

## 报告结构

1. 命盘摘要：基本宫位结构、主星、辅曜、四化和大限概览。
2. 六宫深度：命宫、官禄、财帛、夫妻、福德、迁移的专业解读。
3. 规则溯源：触发规则、原典短句、现代转译、权重和置信等级。
4. 内容安全声明：不做绝对预测，不替代医疗、法律、投资或婚恋重大决策。
5. 行动建议：只输出可验证、低风险、非承诺式建议。
