# 商业化验证报告 v0.1

## 验证问题

- 用户是否愿意分享隐私保护后的宫位卡片。
- 用户是否愿意收藏并再次查看命盘。
- 用户对 `Starter 19`、`Standard 49`、`Premium 99` 三个报告样张档位的兴趣强弱。
- 规则溯源和内容安全说明是否提升可信度。

## 当前实现

- `BetaGrowthPanel` 已接入主原型右侧栏。
- `/api/beta/share-card` 生成分享卡结构，不输出完整出生资料。
- `/api/beta/favorite` 保存再次查看意愿，不保存生日/时刻/地点详情。
- `/api/beta/report-intent` 记录价格档位和兴趣分，不创建支付订单。
- `/api/beta/dashboard` 汇总阶段 4 反馈和阶段 5 Beta 事件。

## 价格测试口径

- `starter_19`：轻量六宫摘要和隐私保护分享卡。
- `standard_49`：六宫专业报告、规则溯源和阶段建议。
- `premium_99`：标准报告加顾问抽检标记和更完整的解释链样张。

## 上线风险

- 顾问未完成规则与文案抽检前，不可宣称正式专业命理服务。
- 真实支付、订单后台、退款和发票仍未实现。
- 当前事件存储为内存实现，只适合本地/原型验证；公开 Beta 前需接入持久化存储。

## 下一步建议

- 用 50-100 名 Beta 用户验证分享率、收藏率和报告意向率。
- 若报告意向率达到 5% 以上，再进入真实支付和订单闭环设计。
- 若内容安全命中较多，优先补文案审查和敏感主题降级。
