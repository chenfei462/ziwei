# 阶段 5「Beta 与商业化」实施说明 v0.1

## 目标

第 17-24 周把封测后的 Web MVP 推进到公开 Beta 和小规模商业验证。阶段内只做体验修复、分享/收藏、报告意向、运营素材和数据看板，不接入真实支付、不开发独立 App、不扩展合盘或流月流日。

## Beta 必做范围

- 稳定开盘、六宫解读、规则溯源、手势/按钮替代和封测反馈入口保持可用。
- 新增基础分享卡：展示宫位、星曜关键词、轻量摘要和隐私说明。
- 新增收藏入口：记录用户愿意再次查看的 chart/palace 快照，不保存完整出生资料。
- 新增报告意向：记录价格档位和 1-5 分兴趣，不创建订单，不收款。
- 新增 Beta 数据看板：汇总分享、收藏、报告意向、封测反馈、内容安全和隐私口径。

## 暂缓范围

- 真实支付、发票、订单后台、权益发放。
- iOS/Android 原生 App 和线下大屏正式部署。
- 全十二宫深度报告、合盘、流月、流日和 AI 自由生成报告。

## 新增接口

- `POST /api/beta/share-card`
- `POST /api/beta/favorite`
- `POST /api/beta/report-intent`
- `GET /api/beta/dashboard`

所有接口默认不返回完整生日、出生时间、地点详情或摄像头画面。`report-intent` 仅返回 `payment_status: intent_only`。

## 验收

- 用户可完成“开盘 -> 六宫解读 -> 溯源 -> 分享/收藏 -> 反馈/报告意向”闭环。
- 分享卡、收藏和事件日志不包含完整出生日期、出生时间、地点详情、视频帧或背景图像。
- 看板指标与阶段 4 反馈数据、阶段 5 事件数据一致。
- 顾问未完成内容抽检前，只能标注为“文化娱乐 Beta 测试版”。
