# 分享卡 v0.1

## 字段

- `title`：宫位名 + Beta share。
- `palace_id` / `palace_label`：当前选中宫位。
- `star_keywords`：主星、辅曜和四化关键词，最多 6 个。
- `summary`：同一规则结果生成的轻量摘要。
- `privacy_note`：明确默认隐藏完整生日、出生时间、地点详情和摄像头画面。
- `share_text`：可用于复制到社群或短视频说明的文本。

## 隐私默认值

- 不展示完整生日。
- 不展示出生时间。
- 不展示地点详情。
- 不包含摄像头视频帧或背景图像。

## 当前边界

分享卡 v0.1 是结构化数据和页面预览，不生成独立图片文件；后续可接入 OG 图或 Canvas 导出。
