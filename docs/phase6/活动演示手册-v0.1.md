# 阶段 6 活动演示手册 v0.1

## 设备清单

- 大屏端：桌面浏览器一台，建议 Chrome / Edge，分辨率 1920x1080 或 4K。
- 控制端：手机或平板一台，通过临时 session 控制大屏。
- AR 预览端：移动浏览器一台；WebXR 或摄像头不可用时自动降级到手动全景星盘。
- 网络：同一局域网或同一可访问域名；演示前确认 `/immersive`、控制端和 AR 页面都能打开。

## 演示流程

1. 打开 `/immersive`，大屏展示 16:9 星盘与 session 短码。
2. 使用控制端 `/immersive/control/{session_id}` 点选财帛宫、切换星曜层、切换大限。
3. 点击 `Enter panorama` 展示全景星垣状态。
4. 点击 `Generate share card` 记录分享卡动作。
5. 打开 `/immersive/ar/{session_id}`，展示 AR 预览或无摄像头降级状态。

## 隐私告知

大屏、控制端、AR 预览和演示日志均不展示或记录完整生日、出生时间、地点详情、摄像头视频帧或背景图像。摄像头相关能力仅用于端侧手势/AR 预览，权限拒绝时保留完整按钮路径。

## 故障降级

- 大屏无法联网：改用同机浏览器打开 `/immersive` 做单机演示。
- 控制端无法连接：直接在大屏页面讲解星盘和隐私设计。
- 摄像头或 WebXR 不可用：AR 页显示 `Manual panorama fallback`，继续用触控/按钮完成演示。
- 手势识别不稳定：保留 5 个 MVP 手势说明，用控制端按钮替代操作。
