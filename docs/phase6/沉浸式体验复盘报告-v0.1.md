# 沉浸式体验复盘报告 v0.1

## 指标

- 演示完成率：是否完成大屏配对、点选宫位、切换层级、切换大限、AR 降级展示。
- 事件同步：本地网络下目标感知延迟 < 250ms。
- 大屏表现：16:9 画面无重叠，动画目标 30fps 以上。
- AR 表现：AR 预览启动目标 < 3 秒；不可用时记录降级率。
- 手势稳定性：5 个 MVP 手势可演示；双手拉开和翻掌只作为候选手势观察。
- 隐私问题：视频帧、完整生日、出生时间和地点详情泄露次数必须为 0。

## 当前 v0.1 结论模板

- 大屏页已提供 16:9 展示框、星盘、session 短码和隐私条。
- 控制端已提供点选宫位、切换星曜层、切换大限、进入全景、切换模式和生成分享卡事件。
- AR 页已提供摄像头不可用时的手动全景降级，不上传视频帧。
- 真实活动前仍需完成现场设备联调、投屏比例确认和顾问/主持人演示脚本彩排。

## 下一步建议

- 若活动演示稳定，再接入真实事件流或 WebSocket。
- 若 AR 降级率高，优先优化非摄像头沉浸体验，而不是强推摄像头权限。
- 若观众主要关注分享与报告，下一阶段优先把大屏演示和报告样张打通。
