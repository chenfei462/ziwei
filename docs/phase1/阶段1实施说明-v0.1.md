# 阶段 1 实施说明 v0.1

阶段 1 已落地为 TypeScript/Node.js 排盘核心库和轻量 API 处理器。

## 运行命令

```bash
npm install
npm run generate:fixtures
npm test
npm run typecheck
npm run build
```

## 交付物

- `src/`：排盘核心、API handler、类型定义、计算追踪和解释占位响应。
- `data/phase1/rule-table-v0.1.json`：规则表 v0.1。
- `data/phase1/test-charts-v0.1.csv`：100 个测试盘种子。
- `docs/phase1/阶段2对接说明-v0.1.md`：阶段 2 前端对接字段和交互映射。

## 正确性边界

底层排盘使用 `iztro` 作为计算后端。当前 100 个测试盘仍是种子数据，其中 `PENDING_CONSULTANT` 不代表专家验收通过。只有紫微顾问补齐并确认 `expected_*` 字段后，才能把对应样例计入 golden tests 和 98% 正确性指标。
