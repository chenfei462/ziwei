# 阶段 2 对接说明 v0.1

阶段 1 排盘引擎向阶段 2「交互原型」提供结构化命盘数据。前端原型不需要理解排盘算法，只需要读取 `Chart`。

## 前端必读字段

- `chart.palaces`：十二宫渲染主数据，包含 `palace_id`、`name`、`branch`、`stem`、`main_stars`、`support_stars`、`transforms`、`relation_refs`。
- `chart.stars`：星曜列表，可用于星曜层级、图标和筛选。
- `chart.transforms`：四化列表，可用于颜色标记。
- `chart.major_periods`：大限区间，可用于时间轮。
- `trace`：顾问和工程调试使用，不直接展示给普通用户。

## 交互映射

- 点选宫位：读取该宫位 `relation_refs.opposite`、`relation_refs.triad`、`relation_refs.neighbors`，依次高亮本宫、对宫、三合、邻宫。
- 捏合缩放：在同一 `palace_id` 下切换主星层、辅曜层和四化层。
- 画圈切换大限：按 `major_periods` 的顺序切换当前阶段宫位。
- 开掌复位：清除选中宫位，回到十二宫全局视图。
- 握拳返回：收起当前卡片或回到上一层。

## 隐私默认

前端分享图默认遵守 API 返回的隐私设置：

- `share_birth_date: false`
- `share_birth_time: false`
- `share_location: false`

阶段 2 不应在分享图或日志里自行拼接完整出生资料。
