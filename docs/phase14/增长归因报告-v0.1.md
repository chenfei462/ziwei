# 增长归因报告 v0.1

## 统计口径

阶段 14 看板按渠道、活动、分享素材类型和转化动作统计。当前事件类型包括：

- `share_opened`
- `invite_visit`
- `daily_theme_created`
- `daily_check_in`
- `challenge_joined`
- `report_intent`

## 渠道口径

支持 `wechat_group`、`mini_program`、`qr_event`、`short_video`、`creator_homepage`、`organic` 六类来源。缺少渠道参数时应降级为 `organic`。

## 关键指标

- 总渠道事件数。
- 唯一 visitor 数。
- 各渠道事件量。
- 分享素材类型生成量。
- 挑战加入事件数。
- 报告意向事件数。

## 隐私审查

看板只展示行为事件和脱敏快照统计，不展示完整出生资料、摄像头内容或地点详情。异常 payload 进入内容安全与隐私回归检查。
