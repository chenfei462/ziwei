# 小程序适配说明 v0.1

## 范围

阶段 14 采用微信小程序 H5 容器 / WebView 优先方案，不新建完整原生小程序工程。小程序入口复用现有 Next.js 页面、分享快照和增长 API。

## 路由

- `/phase14`：渠道分发演示入口。
- `/api/channel/entry`：解析渠道来源、campaign、share_id、referrer 和 visitor_id。
- `/api/member/link-anonymous`：合并匿名 visitor、member_id 和 openid 占位。
- `/api/share/create`：扩展生成 `mini_program_card`、`h5_poster`、`qr_landing`。
- `/api/growth/channel-event`：记录渠道增长事件。
- `/api/ops/growth/channel-dashboard`：读取渠道归因汇总（管理员凭据）。

## 审核降级

如平台审核限制命理表达，所有入口统一降级为“传统文化星曜卡片与自我观察工具”。文案不得包含具体事件预测、硬断、恐吓或重大决策承诺。

## 隐私

渠道参数、分享素材、账号绑定和日志不得包含完整生日、出生时间、地点详情、摄像头帧或背景图像。Openid 在本阶段仅作为占位字段，正式接入前需补齐平台授权与用户告知。
