# 渠道分享素材包 v0.1

## 素材类型

- `mini_program_card`：用于微信群、小程序 WebView 和邀请链路。
- `h5_poster`：用于短视频平台、创作者主页和移动浏览器分享。
- `qr_landing`：用于线下二维码、活动海报和创作者主页。

## 可展示内容

- 今日星垣主题、星曜关键词、轻任务摘要。
- 星曜图鉴卡、成就卡、挑战进度卡和节日主题卡。
- 隐私保护说明和传统文化娱乐定位。

## 禁止内容

- 完整生日、出生时间、地点详情、摄像头画面或背景图像。
- 具体事件预测、硬断、恐吓式表达。
- 医疗、法律、投资、婚恋重大决策承诺。

## 默认安全标记

所有素材默认包含 `daily_observation_only`、`avoid_absolute_prediction` 和 `privacy_redaction_required`。
