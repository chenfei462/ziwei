# 小程序灰度发布说明 v0.1

## 发布策略

阶段 15 默认使用 `mini_program_v0.1`，初始灰度比例为 10%。灰度入口仅开放 `mini_program` 与 `wechat_group` 渠道。

## 回滚条件

- 审核被拒或需要重新提交材料。
- OpenID 绑定错误率异常。
- 分享 payload 出现隐私字段。
- 订阅消息投诉升高。
- WebView 白名单或加载异常影响核心路径。

## 回滚方式

保持 `fallback_to_h5: true`，将入口降级到阶段 14 H5 多渠道分发页，保留渠道参数、分享快照和挑战入口。

## 观察指标

观察登录成功率、绑定去重、分享打开、挑战加入、订阅授权率、提醒事件、审核问题和隐私扫描结果。
