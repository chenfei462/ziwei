# 小程序审核材料 v0.1

## 审核定位

本小程序定位为传统文化星曜卡片与自我观察工具，不提供医疗、法律、投资、心理或婚恋重大决策建议。

## 类目与说明

- 建议类目：文化服务 / 工具 / 兴趣内容。
- 服务说明：用户可查看今日星垣、星曜图鉴、挑战进度和分享卡。
- 演示账号：使用阶段 15 测试账号与体验版二维码。

## 必备材料

- 隐私协议。
- 出生资料用途说明。
- 摄像头与手势识别说明。
- 分享卡脱敏说明。
- 订阅消息用途说明。
- 内容免责声明。
- 审核截图：主页、WebView、分享卡、订阅授权、隐私说明。

## 降级口径

如平台限制命理表达，所有入口统一展示为“传统文化星曜卡片与自我观察工具”，关闭专业判断式文案，只保留轻任务、图鉴和挑战。
