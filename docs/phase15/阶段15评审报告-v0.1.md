# 阶段 15 评审报告 v0.1

## 交付范围

已建立正式小程序上架与平台审核 v0.1 的工程基础：小程序工程壳、微信登录抽象、OpenID 哈希绑定、小程序分享 payload、订阅消息占位、发布灰度开关和审核材料。

## 已覆盖接口

- `POST /api/mini-program/login`
- `POST /api/mini-program/link-member`
- `POST /api/share/create`
- `POST /api/mini-program/subscribe`
- `POST /api/mini-program/reminder-event`
- `GET /api/mini-program/release-gate`

## 验收重点

- 小程序壳可承载 WebView 并透传渠道参数。
- 微信 code 仅用于生成哈希绑定，不保留原始 code 或 openid。
- 分享卡和订阅事件默认脱敏。
- 审核材料具备服务说明、隐私说明、摄像头说明和内容降级策略。

## 暂缓项

- 真实微信服务端 code2session 调用。
- 小程序正式 AppID 与域名白名单配置。
- 小程序云开发、客服消息、交易能力。
- 原生 App、自由社区、复杂内容发布和新命理规则。
