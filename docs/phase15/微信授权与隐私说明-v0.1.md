# 微信授权与隐私说明 v0.1

## 授权范围

- 微信登录：用于生成小程序会话并绑定脱敏会员记录。
- 订阅消息：仅用于今日星垣复访提醒和挑战进度提醒。
- WebView：承载既有 Web/PWA 核心体验。

## OpenID 处理

服务端使用微信 code 换取 openid 后只保存 `openid_hash`，不保存原始 code 或原始 openid。绑定对象为 anonymous visitor、member_id 与 `openid_hash`。

## 不采集内容

小程序登录、分享、订阅、渠道归因和提醒日志均不得保存完整生日、出生时间、地点详情、摄像头帧或背景图像。

## 用户告知

用户进入前应看到服务定位、隐私说明、订阅消息用途和重大决策免责声明。拒绝授权时保持 H5 浏览和按钮路径可用。
