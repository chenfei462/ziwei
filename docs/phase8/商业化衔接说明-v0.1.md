# 商业化衔接说明 v0.1

## 可进入付费验证的模块

- 单盘六宫结构化报告：建议价格档位 `standard_49`。
- 合盘对照报告：建议价格档位 `premium_99`，仅用于沟通风格和合作节奏观察。
- 年度/月度主题报告：建议价格档位 `standard_49` 或与单盘报告打包。

## 暂缓模块

- 真实支付、订单后台、退款、发票、会员权益。
- DOCX 编辑器、批量报告、复杂排版模板后台。
- 全十二宫深度报告、合盘婚恋结果判断、流日预测。

## 上线前条件

- 紫微顾问完成规则表、文案模板和报告样张抽检。
- 内容审查队列能记录 `blocked`、`approved` 和安全标记。
- 隐私测试确认报告、素材卡、脚本和导出预览不包含完整出生资料或摄像头数据。
- Beta 数据证明用户对报告样张有明确购买意向后，再进入真实支付/订单阶段。
