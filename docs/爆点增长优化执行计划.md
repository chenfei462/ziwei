# 爆点增长优化执行计划

## 目标

让首次访问者在首屏理解紫微星垣的用途，并把现有“命盘、今日星垣、分享、报告、小程序承接”能力包装成可传播、可转化的公开体验。

## 本轮完成范围

### P0：一眼知道产品干什么

- 首页首屏改为结果导向：生成紫微观察卡，看见性格结构、关系模式和阶段节奏。
- 首页主 CTA 改为“生成我的观察卡”，降低会员、订单、客服等首访干扰。
- 首页展示真实结果预览，而不是只展示抽象十二宫装饰。

### P0：分享页能二次转化

- 分享页主体增加“我也生成一张”入口。
- 分享承接只透传 `share_id`、`channel`、`campaign` 等安全归因参数，不透传 `visitor_id`。

### P0：结果页突出传播动作

- 命盘页侧栏前置“生成今日星垣卡”。
- 命盘页展示“7 日星垣挑战”，把一次性建盘转成复访和分享理由。

### P1：付费入口更像产品权益

- 报告购买按钮主文案改为“解锁标准报告 49 元 / 解锁高级报告 99 元”。
- 微信支付/支付宝作为支付方式说明，而不是按钮主卖点。

### P1：微信/PWA/小程序承接

- 补齐 `public/icon-192.png` 与 `public/icon-512.png`。
- 小程序 WebView 默认承接正式 `/chart/new`，不再落旧 `/phase14` 或 `/phase15`。
- 小程序入口不传递 `visitor_id`。
