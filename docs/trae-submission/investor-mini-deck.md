# 紫微星垣投资人 8 页 Deck 文稿

## 1. 封面

**紫微星垣**  
一张可解释、可分享、可持续观察的传统文化 AI 观察卡。

一句话：把高门槛紫微斗数转成普通用户看得懂、愿意分享、还能持续复访的 AI 文化体验。

## 2. 用户痛点

传统命理内容有稳定兴趣人群，但大众化产品仍有四个障碍：

- 看不懂：术语、宫位、四化和流年解释门槛高。
- 不敢信：泛 AI 占卜缺少规则来源，容易像随机生成。
- 不敢晒：完整生日、出生时间和地点属于敏感信息。
- 不复访：一次性报告容易“看完即走”，留存弱。

## 3. 产品方案

紫微星垣把一次建盘拆成一条可传播、可留存的产品链路：

```text
免费生成星垣观察卡
-> 查看性格结构、关系模式、阶段节奏
-> 看到传统术语、规则来源、现代解释和安全过滤
-> 生成脱敏分享页
-> 好友二次生成
-> 加入 7 日观察挑战
-> 解锁私密深度报告 / 会员权益
```

## 4. 核心差异化

- 比传统排盘工具更大众：先给现代语言摘要，再给专业规则依据。
- 比泛 AI 占卜更可信：每段解读都能回到规则 trace、术语和置信提示。
- 比真人咨询更低门槛：即时生成、低价、可保存、可复看。
- 比普通测试更安全：公开分享默认隐藏生日、出生时间、地点和真实身份。

## 5. 当前完成度

项目已经具备可演示的完整产品雏形：

- 公开路径：首页、建卡、命盘结果、分享页、报告页、会员、订单、客服、隐私政策和用户协议。
- AI 可信表达：规则 trace、现代语言转译、置信提示、安全过滤和 fallback 说明。
- 商业化雏形：标准/高级报告、权益、订单、沙箱支付和客服兜底。
- 工程基础：Next.js App Router、TypeScript、Vitest、Playwright、Prisma/PostgreSQL readiness、生产部署文档。

## 6. 增长与变现闭环

- 获客：免费星垣观察卡降低首次体验门槛。
- 传播：脱敏分享页适合微信、社群和短视频截图传播。
- 留存：7 日观察挑战已具备可演示闭环，下一阶段用真实流量验证连续打卡。
- 转化：私密深度报告、会员权益和主题追问承接付费。
- 合作：达人、社群、传统文化内容号可作为早期渠道。

## 7. 近期验证指标

下一阶段不继续平均堆功能，而是验证五个关键指标：

- 生成完成率：用户能否顺利拿到第一张观察卡。
- 分享点击率：脱敏分享是否带来二次访问。
- 二次生成率：朋友看到分享后是否愿意生成自己的观察卡。
- 7 日挑战加入率：一次性兴趣能否转成连续复访。
- 报告意向点击率：免费摘要是否能承接到付费报告。

## 8. 资源诉求

需要的不是单纯代码人力，而是能帮助项目从作品进入冷启动验证的资源：

- 种子流量：微信社群、短视频账号、传统文化兴趣社区。
- 商业配置：微信支付、支付宝、短信网关、微信授权和对象存储。
- 内容安全：避免恐吓、绝对化、医疗、投资、法律等高风险表达。
- 用户反馈：真实用户访谈、分享链路测试、付费意愿验证。
- 投资沟通：用小额资金完成 30-60 天冷启动实验，验证生成、分享、留存和转化。

## 现场收束话术

> 今天我不是展示一个“算命页面”，而是展示一个传统文化 AI 产品雏形：它能生成、能解释、能脱敏分享、能连续复访，也已经有报告和支付沙箱闭环。下一步最重要的是用真实流量验证增长和转化。
