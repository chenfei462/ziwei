# 紫微星垣投资人一页纸

## 一句话

紫微星垣把高门槛紫微斗数转成可解释、可脱敏分享、可连续打卡的 AI 观察卡，用免费生成获客，用社交分享扩散，用私密报告和会员权益转化。

## 解决什么问题

传统紫微斗数有明确兴趣人群，但普通用户常遇到三个障碍：

- 术语难懂：命宫、四化、流年、大限等概念需要翻译成现代生活语言。
- 信任不足：泛 AI 占卜容易像随机生成，缺少规则来源和解释依据。
- 分享风险：完整生日、出生时间、地点等信息敏感，不适合公开传播。

紫微星垣的定位不是“预测命运”，而是传统文化、自我观察和轻量情绪价值体验。

## 产品闭环

```text
免费生成星垣观察卡
-> 查看性格结构、关系模式、阶段节奏
-> 展示传统术语、规则来源、现代解释和安全过滤
-> 生成脱敏分享页
-> 好友二次生成
-> 加入 7 日观察挑战
-> 解锁私密深度报告 / 会员权益
```

## 当前已完成

- 公开路径：首页、建卡、命盘结果、报告、分享页、会员、订单、客服、隐私和用户协议。
- AI 可信表达：规则 trace、现代语言转译、置信提示、安全过滤和 fallback 说明。
- 隐私边界：公开分享默认隐藏完整出生日期、出生时间、精确地点和真实身份。
- 商业化雏形：标准/高级报告、权益、订单、沙箱支付、支付 readiness 和客服兜底。
- 工程基础：Next.js App Router、TypeScript、Vitest、Playwright、Prisma/PostgreSQL readiness、生产部署文档。

## 为什么有机会

- 中国用户的真实使用场景首先在移动端、微信、短视频和社群分享。
- 传统命理和星座内容已有成熟消费心智，但需要更现代、更安全、更可解释的产品形态。
- AI 的价值不是“玄学化”，而是降低传统知识理解门槛、提升表达质量、增加追问和复访。
- 免费观察卡适合获客，分享页适合传播，7 日挑战已经具备可演示闭环、适合下一阶段验证留存，私密报告适合变现。

## 商业模式

- 免费观察卡：降低首次使用门槛。
- 标准报告：49 元，解锁六宫细节、规则溯源和保存价值。
- 高级报告：99 元，增加更完整的阶段节奏、导出预览和追问额度。
- 会员权益：更多追问、每日星垣、主题报告和连续挑战。
- 后续合作：达人/社群渠道、传统文化内容号、小程序流量承接。

## 当前最需要验证的指标

- 生成完成率：用户是否能顺利从首页完成第一张观察卡。
- 分享点击率：脱敏分享是否能带来二次访问。
- 二次生成率：好友看到分享后是否愿意生成自己的观察卡。
- 7 日挑战加入率：一次性兴趣能否转成连续复访。
- 报告意向点击率：免费摘要是否能承接到付费报告。

## 近期资源诉求

- 种子流量：微信社群、短视频账号、传统文化兴趣社区。
- 支付和登录配置：微信支付、支付宝、短信网关、微信授权。
- 内容安全评测：避免恐吓、绝对化、医疗/投资/法律等高风险表达。
- 产品打磨：移动端视觉、分享卡、录屏素材、真实用户反馈。
