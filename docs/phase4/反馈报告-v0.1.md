# 阶段 4 反馈报告 v0.1

## 当前状态

工程侧已接入封测说明、反馈入口、隐私确认、反馈 API 和指标汇总口径。真实封测样本尚未开始，因此本报告目前是 v0.1 模板，等待第 14-16 周填入真实数据。

## 指标口径

- 完整流程完成率：`completed_tasks` 同时包含建档开盘、点选宫位、切换模式、查看溯源、手势或按钮替代、提交反馈。
- 分享意愿率：`share_willingness >= 4` 的反馈占比。
- 平均评分：整体评分、解读可信度、手势可用性、分享意愿分别计算 1-5 分均值。
- 问题分布：按 `blocking`、`major`、`minor`、`content_review`、`future_feature` 分类。

## 阶段 4 验收目标

- 完整流程完成率 >= 60%。
- 分享或收藏意愿 >= 20%。
- blocking 问题为 0。
- major 问题进入 Beta 前全部修复或有明确延期决策。
- 硬断、恐吓式表达、重大决策承诺为 0。
