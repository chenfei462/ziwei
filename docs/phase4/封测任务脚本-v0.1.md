# 阶段 4 封测任务脚本 v0.1

## 测试目标

验证 50-100 名封测用户是否能稳定完成 Web MVP 主流程，并收集产品、内容、隐私和手势可用性反馈。

## 测试前提示

- 本产品用于传统文化研究、娱乐互动与自我观察，不构成医疗、法律、投资、婚恋等重大决策建议。
- 出生资料只用于生成本次命盘；分享与反馈默认不包含完整生日、出生时间或地点详情。
- 摄像头手势识别默认端侧运行；反馈只记录手势事件和权限状态，不上传视频帧。

## 用户任务

1. 打开 MVP 页面，阅读“封测说明”。
2. 使用默认演示档案或输入自己的出生资料完成开盘。
3. 点选任意宫位，查看本宫、对宫、三合、邻宫高亮。
4. 在专业/娱乐模式之间切换，比较文案差异。
5. 展开规则溯源，确认能看到规则 ID、来源、短引文和现代转译。
6. 使用一个手势或按钮替代路径完成操作，例如切换星曜层、切换大限、模拟开掌。
7. 提交封测反馈，填写整体评分、解读可信度、手势可用性、分享意愿、问题分类和文字说明。

## 观察重点

- 是否能在 3 分钟内完成主流程。
- 是否理解专业/娱乐模式共用同一命盘结果。
- 是否知道反馈不会上传摄像头画面或完整出生资料。
- 是否愿意分享、收藏或再次体验。
