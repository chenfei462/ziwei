# 阶段 4 修复清单 v0.1

## 分级规则

- `blocking`：阻断开盘、解读、反馈提交或造成隐私泄露，阶段内必须修复。
- `major`：明显影响主流程完成率、移动端可用性或内容安全，进入 Beta 前必须修复。
- `minor`：不阻断体验的 UI、文案、可用性问题，可排期修复。
- `content_review`：需要紫微顾问或内容设计师审查的规则、文案、溯源问题。
- `future_feature`：超出 MVP 的增强建议，不进入阶段 4 修复范围。

## Beta 前必须确认

- blocking 问题数为 0。
- major 问题全部关闭或有产品负责人签字延期。
- content_review 中涉及硬断、恐吓、重大决策承诺的问题全部关闭。
- 反馈数据不包含完整生日、出生时间、地点详情或摄像头画面。
