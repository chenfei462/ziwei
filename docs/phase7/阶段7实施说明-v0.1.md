# 阶段 7「合盘与流年扩展」实施说明 v0.1

## 目标

第 33-40 周把单人 Web Beta 扩展为合盘与年度/月度主题版本。阶段内只做双盘关系观察、六宫年度/月度主题、规则溯源、轻量分享卡和隐私同意，不做真实支付、订单后台、原生 App、流日或具体事件预测。

## 新增能力

- 合盘对照：`POST /api/synastry/create` 支持两张 chart 或匿名 chart snapshot，必须带双方同意。
- 年度/月度主题：`POST /api/timeline/interpret` 支持 year、可选 month、mode、palace_id，范围限定六个 MVP 宫位。
- 前端入口：`/phase7` 提供「合盘对照」和「年度主题」两个面板，支持专业/娱乐切换、规则溯源和分享卡预览。
- 分享脱敏：合盘卡和年度主题卡默认隐藏完整生日、出生时间、地点详情和摄像头数据。

## 暂缓范围

- 真实支付、订单后台、发票、退款和报告权益发放。
- 全十二宫深度流年、流日、具体事件预测和多派别完整配置。
- 原生 iOS/Android App、正式创作者后台和 PDF/DOCX 导出。

## 验收边界

- 合盘定位为沟通风格、合作节奏、互补点、冲突提醒和共同建议，不输出婚姻成败、分手复合等结论。
- 流年/流月只输出主题观察和行动建议，不输出投资、医疗、法律、婚恋等重大决策承诺。
- `data/phase7/*samples-v0.1.csv` 是 30 条合盘和 30 条流年/月度种子样例；顾问确认前只能作为结构测试数据。
- 顾问未完成规则与样例抽检前，本阶段只能标记为工程扩展完成，不能标记为专业内容验收通过。
