# 阶段 7 评审报告 v0.1

## 交付物

- `src/phase7/synastryTimeline.ts`：合盘与年度/月度主题核心逻辑。
- `src/app/api/synastry/create/route.ts`：合盘 API route。
- `src/app/api/timeline/interpret/route.ts`：年度/月度主题 API route。
- `src/app/phase7/page.tsx`：合盘与年度主题前端入口。
- `data/phase7/synastry-rules-v0.1.json`、`data/phase7/timeline-rules-v0.1.json`：规则表 v0.1。
- `data/phase7/synastry-samples-v0.1.csv`、`data/phase7/timeline-samples-v0.1.csv`：各 30 条顾问待审样例。

## 内容安全检查

- 禁止词方向：必然、一定、死亡、绝症、破产、离婚、分手复合承诺。
- 合盘敏感主题必须带 `relationship_decision_guard` 或等价标记。
- 财务相关主题必须带 `financial_decision_guard` 或重大决策安全提醒。
- 年度/月度主题必须带 `annual_theme_only` 或 `monthly_observation_only`，不得扩展为流日或具体事件预测。

## 隐私检查

- 合盘必须确认双方同意。
- API 响应、前端展示、分享卡不输出完整生日、出生时间、地点详情或摄像头画面。
- chart snapshot 仅用于当前 API 计算，不新增持久化出生资料。

## 阶段出口

- 工程验收：单元、路由、组件、E2E、typecheck、build 全部通过。
- 专业验收：紫微顾问完成规则表与 60 条种子样例抽检后才可标记通过。
- 下一阶段建议：若合盘和年度主题反馈稳定，再进入报告导出/创作者后台；若内容争议较多，先扩大顾问审查而不是扩展规则范围。
