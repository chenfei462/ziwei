# 2026-06-08 报告体系正式交付增量

本次增量补齐报告体系的正式交付追溯链，不以规划文档替代实现。

## 已落地

- `ReportDraft` 新增 `report_version`、`access`、`lineage`、`share_summary` 和 `export_options`。
- `createReportDraft` 会写入付费私密访问层、免费脱敏摘要开关、规则版本、AI prompt 版本、生成时间和导出 readiness。
- `/api/report/[id]/share` 改为只读取 `share_summary` 生成公开分享快照，不再从完整报告正文临时拼接公开摘要。
- PostgreSQL adapter 写入 `reports.access_policy/share_summary/current_version` 和 `report_versions.prompt_version/generated_at`，不再用 rule version 代替 prompt version。
- `/report/[id]` 页面展示报告版本、模板版本、规则版本、AI prompt 版本和访问层提示，便于用户、客服和运营回查。
- `/report/[id]` 对未购买但拥有命盘的用户展示免费脱敏摘要、追溯信息和购买完整报告入口；陌生人仍不可访问；已购买标准或高级权益后才展示宫位详情、规则来源和私密报告操作。
- 命盘页和报告免费摘要页共用 `ReportPurchaseAction`，可直接创建微信支付或支付宝结账会话，并展示 provider 返回的支付入口；缺少真实商户配置时只进入 `/commercial/checkout-sandbox` 接入验证页，不伪装生产支付。
- `/commercial/checkout-sandbox` 展示脱敏的 session/order 引用、取消返回入口和生产 webhook 验签提示，不展示手机号、出生资料、微信身份标识、支付密钥或完整报告正文。
- 2026-06-09 增补：`/commercial/checkout-sandbox` 新增“确认沙箱支付”按钮，调用 `/api/checkout/sandbox/confirm`，由服务端校验订单归属、消费已签名 sandbox webhook、走原有验签/幂等/权益发放链路；生产环境默认失败关闭，必须显式设置 `ZIWEI_ENABLE_SANDBOX_CHECKOUT_CONFIRM=true` 才允许本地/预发验证。
- `MemberEntitlement`、Prisma schema 和 PostgreSQL migration 新增 `tier_id`、`access_level`、`benefits`，用于区分免费摘要、标准报告和高级报告权益。
- `starter_19` 仅发放 `free_summary` 与 `redacted_share` 权益，`can_read_report=false`；`standard_49` 与 `premium_99` 发放完整报告阅读、导出预览和收藏权益，高级报告额外标记优先客服。
- `/api/ops/reports` 的脱敏摘要补充报告版本、prompt 版本、访问策略和免费摘要开关，不返回报告正文或完整 trace。
